# ГидроCRM

CRM для сервисной компании, которая ремонтирует и собирает гидростанции. Заявки из всех каналов, заказы по этапам с проверками, сметы с согласованием, выезды мастеров, лента заказа и чат команды — в одной системе вместо разрозненных мессенджеров и таблиц.

**Демо:** вход под любой из четырёх ролей, данные вымышленные, нажимать можно всё.

![Превью](apps/web/public/og-image.png)

## Что умеет
- **Заявки** из телефона, почты, сайта и мессенджеров: срок первой реакции, автоматическое назначение менеджера, превращение заявки в заказ в два клика.
- **Четыре воронки**: ремонт в цеху, выездной ремонт, сборка под заказ, сборка типовых станций. Этапы и нормы времени настраиваются.
- **Проверки этапов**: нельзя начать ремонт без согласованной сметы, выдать заказ с несогласованными доп. работами, назначить ремонт без мастера. Руководитель может пропустить проверку только с комментарием — это попадает в журнал.
- **Смета**: работы, запчасти, услуги, скидки, маржа. Мастер предлагает позиции без цен, менеджер утверждает. Согласование фиксируется с версией и суммой.
- **Роли и права**: руководитель, менеджер, мастер, бухгалтер, администратор. Мастер видит только свои заказы и не видит цен — эти поля не уходят с сервера.
- **Общение**: лента каждого заказа с фото и @упоминаниями, чат команды, уведомления. Изменения коллег появляются на экране без перезагрузки (WebSocket).
- **Выезды**: календарь с перетаскиванием, предупреждение о пересечениях, экран мастера на объекте с большими кнопками и работой без связи.
- **Клиенты и оборудование**: поиск по телефону в любом формате, ИНН, серийному номеру; история ремонтов каждой станции.
- **Дашборд руководителя**: заказы без движения, просрочки, выручка и маржа за месяц.
- **Мобильная версия** устанавливается на телефон как приложение (PWA).

## Стек
| Слой | Технологии |
|---|---|
| Сервер | NestJS 11, Prisma 6, PostgreSQL 17, Socket.IO, Zod |
| Интерфейс | React 18, TypeScript, Ant Design 5, TanStack Query, React Router, PWA |
| Общий код | `packages/shared` — схемы проверки, права, правила этапов, расчёт сметы используются и сервером, и интерфейсом |
| Качество | Vitest, ESLint, строгий TypeScript |

## Архитектура
```
apps/api        NestJS: REST + WebSocket, изоляция данных компаний, журнал действий
apps/web        React: интерфейс для ПК и смартфона
packages/shared Zod-схемы, права ролей, правила переходов этапов, расчёт сметы
docs/           техническое задание, аудит, отчёт о безопасности
```
Ключевые решения:
- **Изоляция компаний** на уровне ORM: расширение Prisma само добавляет `companyId` во все запросы — система готова к продаже нескольким компаниям.
- **Права на сервере**: скрытые поля не попадают в ответ API, интерфейс только отражает права.
- **Правила этапов — чистая функция** в общем пакете, покрыта тестами и используется сервером и демо одинаково.
- **Демо без сервера**: для портфолио интерфейс собирается вместе с демо-сервером, работающим в браузере, — те же эндпоинты, схемы и правила, данные посетителя хранятся у него.

## Запуск для разработки
Нужны Node.js 20+ и pnpm 9. Docker не обязателен — PostgreSQL запускается встроенным пакетом.
```bash
pnpm install
cp apps/api/.env.example apps/api/.env
pnpm db                 # PostgreSQL (оставить запущенным)
pnpm db:migrate         # схема БД
pnpm db:demo            # демо-данные (или pnpm db:seed — пустая компания)
pnpm --filter @hydrocrm/api dev
pnpm --filter @hydrocrm/web dev   # http://localhost:5173
```
Для входа по ролям в `apps/api/.env` включите `DEMO_MODE=true`.

## Демо-сборка для GitHub Pages
```bash
pnpm demo:export                      # снимок демо-данных → apps/web/public/demo/snapshot.json
pnpm build:demo /hydrocrm/            # apps/web/dist-demo — готово к публикации
```
Публикацию выполняет GitHub Actions (`.github/workflows/pages.yml`) при каждом push в `main`.
