# Модуль 06. Задачи и уведомления сотрудникам

Задачи со сроками и система уведомлений, чтобы никто ничего не забывал. Сущности: `Task`, `Notification`, `NotificationPreference`, `PushSubscription` ([Модель данных](../03-модель-данных.md#9-задачи-и-уведомления)).

## 1. Задачи
- **ЗАД-1** (Э1, обязательно). Поля: название, описание, исполнитель, срок (дата или дата+время), напоминание, приоритет, привязка к заказу, клиенту или заявке.
- **ЗАД-2** (Э1, обязательно). Задачу можно создать из любой карточки (заказ, клиент, заявка), из сообщения ленты или чата («Создать задачу из сообщения») и с отдельного экрана.
- **ЗАД-3** (Э1, обязательно). Экран «Мои задачи»: группы «Просрочены», «Сегодня», «Завтра», «На неделе», «Без срока», «Поставленные мной». На главном экране сотрудника — виджет задач на сегодня.
- **ЗАД-4** (Э1, обязательно). Статусы: открыта, выполнена (с необязательным комментарием результата), отменена. Выполнение и отмена видны в ленте связанного заказа.
- **ЗАД-5** (Э1, обязательно). Автор задачи получает уведомление о её выполнении.
- **ЗАД-6** (Э1, обязательно). Просроченные задачи подсвечиваются, исполнитель получает уведомление в момент просрочки, руководитель видит список просроченных по команде.
- **ЗАД-7** (Э1, обязательно). Автоматические задачи, создаваемые системой:

| Событие | Задача | Кому | Этап |
|---|---|---|---|
| Результат выезда «Нужен повторный выезд» | Запланировать повторный выезд | Менеджер заказа | Э1 |
| Скидка выше лимита | Подтвердить скидку | Руководитель | Э1 |
| Смета на согласовании дольше 2 дней | Напомнить клиенту о смете | Менеджер | Э1 |
| Заказ готов к выдаче дольше 3 дней | Связаться с клиентом по выдаче | Менеджер | Э1 |
| Остаток запчасти ниже минимума | Заказать у поставщика | Бухгалтер | Э2 |
| Счёт просрочен | Напомнить об оплате | Менеджер и бухгалтер | Э2 |
| Гарантия заканчивается через 14 дней | Предложить ТО | Менеджер | Э2 |
| Ошибка обмена с 1С | Проверить обмен | Бухгалтер | Э3 |

Правила (сроки, получатели, включение) настраиваются в настройках.
- **ЗАД-8** (Э3, желательно). Повторяющиеся задачи (ежедневно, еженедельно, ежемесячно), например «Инвентаризация склада в последнюю пятницу месяца».
- **ЗАД-9** (Э3, желательно). Чек-листы внутри задачи.

## 2. Уведомления сотрудникам
### Каналы
| Канал | Как работает | Этап |
|---|---|---|
| В CRM | Колокольчик со счётчиком, список уведомлений, всплывающее сообщение, если CRM открыта | Э1 |
| Push | Web Push на ПК и смартфон (PWA). На iOS — только для PWA, установленного на главный экран | Э1 |
| Telegram | Сообщения от служебного бота сотруднику (сотрудник привязывает Telegram в профиле по одноразовой ссылке) | Э1 |

### Требования
- **ЗАД-20** (Э1, обязательно). Типы уведомлений и каналы по умолчанию:

| Тип | В CRM | Push | Telegram |
|---|---|---|---|
| Новая заявка мне / всем менеджерам | ✔ | ✔ | ✔ |
| Заявка просрочена | ✔ | ✔ | ✔ |
| Мне назначен заказ / я исполнитель | ✔ | ✔ | ✔ |
| Смена этапа моего заказа | ✔ | | |
| Упоминание `@` | ✔ | ✔ | ✔ |
| Новый комментарий в заказе, за которым я слежу | ✔ | ✔ | |
| Новое сообщение в чате | ✔ | ✔ | |
| Мне поставлена задача | ✔ | ✔ | ✔ |
| Напоминание о задаче / задача просрочена | ✔ | ✔ | ✔ |
| Выезд назначен / напоминание о выезде | ✔ | ✔ | ✔ |
| Заказ без движения | ✔ | | ✔ |
| Сообщение от клиента | ✔ | ✔ | |
| Остаток ниже минимума | ✔ | | |
| Оплата поступила | ✔ | | |

- **ЗАД-21** (Э1, обязательно). Каждый сотрудник в профиле включает и выключает каналы по типам.
- **ЗАД-22** (Э1, обязательно). Режим «Не беспокоить»: в нерабочее время push и Telegram не отправляются (кроме типов, отмеченных как срочные руководителем). Уведомления в CRM копятся.
- **ЗАД-23** (Э1, обязательно). Клик по уведомлению открывает нужный объект (заказ, задачу, сообщение).
- **ЗАД-24** (Э1, обязательно). Отправка push и Telegram — через очередь с повторами (3 попытки). Недоставленный push (подписка устарела) удаляет подписку.
- **ЗАД-25** (Э1, обязательно). Уведомления группируются: 5 комментариев в одном заказе за 10 минут — одно push-уведомление «5 новых комментариев в З-2026-0042».
- **ЗАД-26** (Э1, обязательно). Автор действия не получает уведомление о собственном действии.
- **ЗАД-27** (Э1, желательно). Утренняя сводка в Telegram в 8:30: мои задачи на сегодня, выезды, просроченное. Для руководителя — сводка по компании (новые заявки, застрявшие заказы, поступления).

## Критерии приёмки
- Менеджер ставит мастеру задачу из комментария, мастер получает push на смартфон и Telegram-сообщение, по клику открывается задача.
- После выполнения задачи автор получает уведомление, в ленте заказа появляется событие.
- В 21:00 push не приходит, уведомление ждёт в колокольчике.
- Просроченная задача видна руководителю в списке просроченных.
