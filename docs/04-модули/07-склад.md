# Модуль 07. Склад и запчасти

Полноценный учёт запчастей и комплектующих: остатки, приход, резерв и списание под заказ, поставщики, закупки, инвентаризация. Сейчас около 20 позиций, но модуль рассчитан на сотни. Сущности: `Product`, `ProductBom`, `Warehouse`, `StockMovement`, `StockBalance`, `Supplier`, `Purchase`, `Inventory` ([Модель данных](../03-модель-данных.md#10-склад)). Весь модуль — этап Э2.

## 1. Основные понятия
- **На складе** (`on_hand`) — физически лежит.
- **В резерве** (`reserved`) — закреплено за заказами, но не списано.
- **Доступно** = на складе − в резерве. Резервировать можно только доступное.
- **Себестоимость** — средневзвешенная: при каждом приходе пересчитывается `avg_cost_kop = (остаток × старая себестоимость + приход × цена прихода) / (остаток + приход)`. Списание идёт по текущей средней себестоимости.

## 2. Экраны
1. **Остатки** — таблица номенклатуры с остатками.
2. **Карточка номенклатуры** — параметры, остатки по складам, история движений, в каких заказах использовалась.
3. **Приход** — оформление поступления.
4. **Закупки** — список и карточка закупки.
5. **Поставщики**.
6. **Инвентаризация**.
7. **Журнал движений** — все движения с фильтрами.

## 3. Требования

### Номенклатура
- **СКЛ-1** (Э2, обязательно). Виды: запчасть, комплектующее, типовая станция, расходник. Поля — см. модель `Product`.
- **СКЛ-2** (Э2, обязательно). Работы и услуги ведутся в том же справочнике с отметкой «Услуга» (не складская позиция, остатков нет) — это прайс работ для смет.
- **СКЛ-3** (Э2, обязательно). Для типовой станции задаётся состав (BOM): список комплектующих с количеством, и шаблон работ сборки.
- **СКЛ-4** (Э2, обязательно). Импорт номенклатуры из Excel (артикул, название, единица, категория, цена закупки, цена продажи, остаток, минимальный остаток) — для первоначального заполнения.
- **СКЛ-5** (Э2, желательно). Аналоги: у позиции можно указать взаимозаменяемые позиции, при нехватке система предлагает аналог.

### Остатки
- **СКЛ-10** (Э2, обязательно). Таблица: артикул, наименование, категория, на складе, в резерве, доступно, мин. остаток, себестоимость, сумма остатка (по правам). Фильтры: категория, склад, «ниже минимума», «есть резерв», «нулевые».
- **СКЛ-11** (Э2, обязательно). Позиции ниже минимального остатка подсвечиваются. При переходе ниже минимума создаётся уведомление и задача бухгалтеру (ЗАД-7).
- **СКЛ-12** (Э2, обязательно). Остаток никогда не уходит в минус: списание больше доступного блокируется с сообщением.

### Приход
- **СКЛ-20** (Э2, обязательно). Приход: поставщик, дата, номер документа поставщика, строки (номенклатура, количество, цена). Можно оформить по закупке (строки подставляются) или без неё.
- **СКЛ-21** (Э2, обязательно). Новую позицию можно создать прямо в форме прихода.
- **СКЛ-22** (Э2, обязательно). После проведения прихода пересчитываются остатки и себестоимость. Если приход по закупке под заказ — запчасти автоматически резервируются под этот заказ, менеджер и мастер заказа получают уведомление «Запчасти пришли».
- **СКЛ-23** (Э2, обязательно). Проведённый приход нельзя изменить, только сторнировать (создать обратное движение) с комментарием.

### Резерв и списание под заказ
- **СКЛ-30** (Э2, обязательно). При добавлении запчасти в смету и её согласовании (ЗАК-44) система резервирует доступное количество. Если доступного не хватает — строка помечается «Нет в наличии (не хватает N)», предлагается «Создать закупку».
- **СКЛ-31** (Э2, обязательно). Если все недостающие запчасти по заказу заказаны, заказ можно перевести в «Ожидание запчастей». Когда всё пришло, менеджер получает уведомление.
- **СКЛ-32** (Э2, обязательно). Мастер на этапе ремонта/сборки отмечает «Установлено» по строке — запчасть списывается под заказ (резерв снимается, `on_hand` уменьшается), себестоимость фиксируется в позиции заказа.
- **СКЛ-33** (Э2, обязательно). Если запчасть из сметы не понадобилась — «Снять резерв». Если клиент отказался от позиции — резерв снимается автоматически.
- **СКЛ-34** (Э2, обязательно). При отказе от заказа все резервы снимаются, списанные запчасти можно вернуть на склад («Возврат»).
- **СКЛ-35** (Э2, обязательно). Списание без заказа (брак, собственные нужды) — только бухгалтер и руководитель, с обязательной причиной.
- **СКЛ-36** (Э2, обязательно). Старые снятые с агрегата детали не учитываются на складе (по умолчанию). Если деталь годна для восстановления, её можно оприходовать как «Б/у» отдельной позицией.

### Сборка типовой станции на склад
- **СКЛ-40** (Э2, обязательно). При завершении заказа «Сборка типовой» с клиентом «Собственный склад» комплектующие списываются по составу, а станция приходует на склад по себестоимости = сумма комплектующих + работы.
- **СКЛ-41** (Э2, обязательно). Продажа станции со склада — заказ «Сборка типовой», где вместо сборки резервируется готовая станция.

### Поставщики и закупки
- **СКЛ-50** (Э2, обязательно). Поставщик: название, ИНН, контакты, заметка, позиции, которые у него покупаем, история закупок и цен.
- **СКЛ-51** (Э2, обязательно). Закупка: поставщик, строки, ожидаемая дата, статус (`draft` → `ordered` → `partially_received` → `received` / `cancelled`), привязка к заказу (необязательно).
- **СКЛ-52** (Э2, обязательно). «Создать закупку по дефициту»: система собирает в черновик все позиции ниже минимума и недостающие под заказы, группирует по основному поставщику.
- **СКЛ-53** (Э2, обязательно). Просроченная закупка (ожидаемая дата прошла, не получена) подсвечивается, бухгалтер получает уведомление.
- **СКЛ-54** (Э3, желательно). Отправка заявки поставщику на почту PDF-файлом из карточки закупки.

### Инвентаризация
- **СКЛ-60** (Э2, обязательно). Создание инвентаризации по складу (все позиции или по категории): система показывает учётные остатки, кладовщик вводит фактические.
- **СКЛ-61** (Э2, обязательно). При проведении расхождения оформляются корректировками (`adjustment`) с указанием инвентаризации. Результат — процент точности остатков (метрика «Точность остатков»).
- **СКЛ-62** (Э2, желательно). Ввод факта со смартфона, поиск позиции сканированием штрихкода камерой (если на позициях есть наклейки).

### Перемещения
- **СКЛ-70** (Э2, обязательно). Перемещение между складами: «Цех» → «Выезд — <мастер>» и обратно (для выездов, ВЫЕ-20).

## 4. Целостность данных
- **СКЛ-80** (Э2, обязательно). Каждое движение и обновление `stock_balances` выполняются в одной транзакции с блокировкой строки остатка (`SELECT … FOR UPDATE`). Два одновременных списания не могут увести остаток в минус.
- **СКЛ-81** (Э2, обязательно). Остатки всегда можно пересчитать из журнала движений (служебная команда `stock:recalculate`), результат должен совпасть с `stock_balances`. Тест проверяет это на каждом изменении склада.
- **СКЛ-82** (Э2, обязательно). Движения не удаляются и не редактируются — только сторно.

## Критерии приёмки
- Приход 10 шт по 1 000 ₽ при остатке 10 шт по 800 ₽ даёт себестоимость 900 ₽.
- Смета согласована → запчасти зарезервированы, доступный остаток уменьшился. Не хватает — предложена закупка.
- Мастер отметил «Установлено» → остаток уменьшился, в позиции заказа записана себестоимость, маржа пересчиталась.
- Одновременное списание последней единицы двумя пользователями — один получает ошибку «Недостаточно на складе».
- Инвентаризация с расхождением создаёт корректировку, точность считается правильно.
