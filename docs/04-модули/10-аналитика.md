# Модуль 10. Аналитика

Отчёты для руководителя: деньги, воронка и источники, загрузка команды, склад. Плюс метрики успеха проекта из раздела 8 [«Идеи проекта»](../../Идея%20проекта.md). Основной объём — этап Э3, простой дашборд — Э1.

## 1. Общие требования
- **АНЛ-1** (Э3, обязательно). Каждый отчёт: выбор периода (сегодня, неделя, месяц, квартал, год, произвольный), сравнение с предыдущим периодом (рост/падение в % со стрелкой), фильтры (тип заказа, менеджер, мастер, источник).
- **АНЛ-2** (Э3, обязательно). Клик по цифре открывает список заказов/заявок, из которых она посчитана.
- **АНЛ-3** (Э3, обязательно). Выгрузка любого отчёта в Excel.
- **АНЛ-4** (Э3, обязательно). Отчёты считаются запросами к БД на лету (при текущем объёме данных это быстро). Для тяжёлых отчётов — кеш на 10 минут.
- **АНЛ-5** (Э3, обязательно). Деньги считаются по датам оплат (касса) или по датам закрытия заказов (выручка) — переключатель в отчёте.

## 2. Дашборд руководителя
- **АНЛ-10** (Э1, обязательно). Простой дашборд MVP: новые заявки сегодня/за неделю, просроченные заявки, заказы в работе по этапам (число), застрявшие заказы, просроченные задачи по сотрудникам, выезды сегодня.
- **АНЛ-11** (Э3, обязательно). Полный дашборд: плитки «Выручка за месяц», «Маржа», «Долги клиентов», «Новые заявки», «Конверсия», «Заказов в работе», «Средний срок ремонта», «Остатки ниже минимума» + графики ниже.

## 3. Отчёты
### 3.1. Деньги
- **АНЛ-20** (Э3, обязательно). Выручка по месяцам (столбцы), с разбивкой по типам заказов.
- **АНЛ-21** (Э3, обязательно). Маржа: по заказам (таблица: заказ, выручка, себестоимость запчастей, себестоимость работ — если ведётся учёт часов, маржа ₽ и %), по типам заказов, по клиентам, по менеджерам.
- **АНЛ-22** (Э3, обязательно). Дебиторка: кто сколько должен, с разбивкой «в срок» / «просрочено до 30 дней» / «более 30 дней».
- **АНЛ-23** (Э3, обязательно). План/факт: руководитель задаёт план выручки на месяц (общий и по менеджерам), отчёт показывает выполнение.
- **АНЛ-24** (Э3, обязательно). Неоплаченные выданные заказы.
- **АНЛ-25** (Э3, желательно). Средний чек по типам заказов и клиентам.

### 3.2. Воронка и источники
- **АНЛ-30** (Э3, обязательно). Заявки по каналам и источникам: количество, конверсия в заказ, сумма заказов, средний чек.
- **АНЛ-31** (Э3, обязательно). Воронка по каждому типу заказа: сколько заказов дошло до каждого этапа, конверсия между этапами, где чаще отказы.
- **АНЛ-32** (Э3, обязательно). Причины отказов (заявки и заказы).
- **АНЛ-33** (Э3, обязательно). Время первой реакции на заявки: среднее, медиана, доля в срок, по менеджерам.
- **АНЛ-34** (Э3, обязательно). Повторные клиенты: доля, число заказов на клиента.

### 3.3. Команда
- **АНЛ-40** (Э3, обязательно). Загрузка мастеров: заказы в работе на каждого, выполнено за период, часы (если ведётся учёт), выезды.
- **АНЛ-41** (Э3, обязательно). Менеджеры: заявки, конверсия, выручка, время реакции, просроченные задачи.
- **АНЛ-42** (Э3, обязательно). Сроки: средний срок ремонта (приёмка → выдача) и сборки (предоплата → отгрузка), среднее время на каждом этапе, доля просроченных заказов.
- **АНЛ-43** (Э3, обязательно). Выезды, закрытые с первого раза, по мастерам.
- **АНЛ-44** (Э3, обязательно). Гарантийные возвраты по мастерам и типам поломок.

### 3.4. Склад
- **АНЛ-50** (Э3, обязательно). Остатки на дату в количестве и деньгах.
- **АНЛ-51** (Э3, обязательно). Оборачиваемость: расход по позициям за период, сколько дней хватит текущего остатка.
- **АНЛ-52** (Э3, обязательно). Дефицит: ниже минимума, ожидаются по закупкам, не хватает под заказы.
- **АНЛ-53** (Э3, обязательно). Простои из-за запчастей: время заказов на этапе «Ожидание запчастей».
- **АНЛ-54** (Э3, желательно). ABC-анализ запчастей по расходу.

## 4. Метрики успеха проекта
- **АНЛ-60** (Э3, обязательно). Отдельная страница «Эффект от CRM» с метриками из раздела 8 «Идеи проекта», которые система может посчитать сама: доля заявок в CRM (из заявок по каналам), потерянные заявки, время реакции, конверсия, обсуждение заказов в CRM, сроки ремонта и сборки, просрочки, выезды с первого раза, маржа, дебиторка, расхождения с 1С, точность остатков, документы из CRM, гарантийные возвраты, активные пользователи.
- **АНЛ-61** (Э3, обязательно). Для каждой метрики можно ввести «Точку отсчёта» (значение до внедрения) и цель. Показывается текущее значение, точка отсчёта, цель и динамика по месяцам.
- **АНЛ-62** (Э3, обязательно). Метрики, которые меряются опросом (время на поиск информации, рутина, удовлетворённость), вводятся вручную раз в месяц.

## Критерии приёмки
- Цифры дашборда совпадают со списками, которые открываются по клику.
- Выручка и маржа за месяц сходятся с суммой по заказам, проверенной вручную на тестовых данных.
- Менеджер не видит отчёты по деньгам, мастер — никакие отчёты.
- Отчёт выгружается в Excel с теми же цифрами.
